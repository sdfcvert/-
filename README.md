# ブラウザゲームプラットフォーム

本格的なブラウザゲームプラットフォームのコア部分です。

## 📁 プロジェクト構造

```
/
├── index.html              # ホーム画面（説明ページ）
├── games.html              # ゲーム選択画面
├── css/
│   └── style.css          # メインスタイルシート
├── js/
│   ├── games-config.js    # ゲーム設定ファイル
│   └── main.js            # メインJavaScript
└── games/                  # ゲームファイルを格納するディレクトリ
```

## 🎮 ゲームの追加方法

新しいゲームを追加するのは非常に簡単です：

### ステップ 1: ゲームファイルを配置

`games/` ディレクトリ内に新しいフォルダを作成します：

```
games/
└── my-game/
    ├── index.html
    ├── style.css
    └── script.js
```

### ステップ 2: games-config.js に追加

`js/games-config.js` を開き、`GAMES` 配列に新しいエントリを追加します：

```javascript
{
    id: "my-game",
    name: "私のゲーム",
    description: "楽しいゲームです",
    icon: "🎮",
    url: "games/my-game/",
    status: "available"
}
```

これだけです！ゲームが自動的にゲーム選択画面に表示されます。

## 🔧 ゲーム設定オプション

各ゲームは以下の設定を持ちます：

| プロパティ | 説明 | 必須 |
|----------|------|------|
| `id` | ユニークな識別子 | ✅ |
| `name` | 表示されるゲーム名 | ✅ |
| `description` | ゲームの説明文 | ✅ |
| `icon` | アイコン（絵文字または画像パス） | ✅ |
| `url` | ゲームへのパス | ✅ |
| `status` | ステータス（available/coming-soon/maintenance） | ✅ |

## 🎨 ステータスタイプ

- **available**: プレイ可能（緑色）
- **coming-soon**: 近日公開（オレンジ色）
- **maintenance**: メンテナンス中（赤色）

## 🚀 使い方

1. `index.html` をブラウザで開く
2. 「スタート」ボタンをクリック
3. プレイしたいゲームを選択
